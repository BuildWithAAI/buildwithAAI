# Telegram Tools

**Status:** idea collection. AAI Scan has private prototype code for a Telegram workflow; live Telegram delivery remains unvalidated and hosting is paused. Other tools are proposals.

## The idea

Build small bots that make everyday work easier for communities and developers. Start with one problem that someone can explain without reference to a token price.

Possible community proposals include release digests, project updates, research bookmarks, task coordination, and opt-in notifications. These are examples for discussion, not approved features.

## A useful proposal answers

1. Who uses the bot, and what takes too much effort today?
2. What input does the person provide, and what output do they receive?
3. Which commands and permissions are needed?
4. What information is stored, for how long, and how is it deleted?
5. What happens when an external service fails?
6. What does it cost to operate for a small group?

## Proposed first version

One main workflow, a short help command, a reproducible demo using synthetic or shareable data, and a documented operating cost. A general-purpose platform can wait until several small tools demonstrate a common need.

## First community output

Submit a short user flow and example conversation for one bot. Collect feedback before deciding whether it deserves a code repository.
