# Community tool ideas

These are founder-supplied ideas, not a list of approved or deployed products. Use the proposal process to choose one small output at a time. No token purchase is needed to contribute.

| Tool | Possible capability | First reviewable result | Proposal |
| --- | --- | --- | --- |
| Telegram bot | Verified links and token facts, sourced charts/statistics/holder observations, scam-link warnings, community commands, GitHub/proposal notices | Command/conversation specification with unknown/stale-data behavior | [AAI-P-0001](../proposals/ideas/AAI-P-0001-telegram.md) |
| Community dashboard | Supply, holders, transactions, trading statistics, disclosed wallets, development/roadmap status and optional contributor recognition | Synthetic read-only wireframe plus metric definitions | [AAI-P-0002](../proposals/ideas/AAI-P-0002-dashboard.md) |
| Development tracker | Milestones, issues, PRs, releases, contributors, recent work and next tasks | Read-only GitHub activity mockup distinguishing merged from deployed | [AAI-P-0003](../proposals/ideas/AAI-P-0003-tracker.md) |
| Meme/media tools | Meme generator, templates, GIFs, graphics, stickers and X assets | Small licensed template set with no invented token claims | [AAI-P-0004](../proposals/ideas/AAI-P-0004-media.md) |
| Wallet/on-chain experiments | Profiles, badges, achievements, reputation, collectibles, community games, feedback votes and token-gated access | Threat model and synthetic user flow; no mainnet transactions | [AAI-P-0005](../proposals/ideas/AAI-P-0005-wallets.md) |
| Bounties | Reviewed community tasks with explicit funding and acceptance terms | Written policy proposal only | [AAI-P-0006](../proposals/ideas/AAI-P-0006-bounties.md) |
| Discord integration | Approved community notices and commands | Permissions and opt-in channel design | [Task AAI-T-018](../tasks/BACKLOG.md#aai-t-018) |
| Community website | Explain status, verified links, proposals and current work | Mobile-friendly page specification | [Task AAI-T-011](../tasks/BACKLOG.md#aai-t-011) |

Existing [AAI Scan](AAI_SCAN.md) is a private pilot with a separate codebase. This catalogue neither republishes that code nor turns proposed community-bot commands into working features. Wallet/payments ideas in [AAI utility](AAI_UTILITY.md) remain design research. A tool must be useful before a token-related feature is considered.

The future blockchain name is undecided between Zoora Blockchain and AAI Blockchain. None of these tools creates native currency, migration, governance or ownership rights on that future network.
