# Prompt 2 — Build the reusable characters once

Apply the Zoora AI project instructions and inspect both attached approved model sheets.

Build the reusable ZOO and Badger character assets for our videos. Match the approved drawings closely enough that these are recognizably the SAME characters.

Create clean layered vector assets or equivalent editable animation components. Separate the parts needed for animation: body, head, hair, facial features, mouth, arms/hands and legs for ZOO; body, head, folded ears, eyes, muzzle, legs and tail for Badger. Keep costume details and markings attached to their correct parts.

Prepare front, 3/4, side and back views; four expressions per character; ZOO's six mouth shapes; pointing and typing poses; Badger's sitting, lying, walking and upward-looking poses.

Record exact palette values, relative character scale, anatomical left/right, pivot points and Badger's fixed spot paths/IDs in a concise reusable character manifest. Use the approved coat maps, not randomized spot generation. Save a versioned baseline and reuse it for later episodes.

Create a 10-second landscape animation proof on the light-grey background:
0–3 seconds: ZOO and Badger stand together, matching the comparison panel. ZOO gives one natural blink and a small brow lift.
3–6 seconds: ZOO makes a restrained pointing gesture. Badger looks toward the gesture with a small head turn.
6–10 seconds: ZOO returns to deadpan. Badger looks up at him, then gives a restrained judging reaction.

Keep this proof silent unless a narration asset is supplied. Demonstrate mouth shapes separately without claiming audio lip-sync.

Provide the editable assets, manifest, animation source and rendered preview if supported. Compare the actual preview against the model sheets and repair obvious differences. If a required tool is missing, complete the usable assets/source and identify the exact remaining rendering step.
