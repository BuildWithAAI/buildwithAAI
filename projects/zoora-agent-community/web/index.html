Wallet options and mobile setup

Choose any detected wallet with a Solana account that supports message signing. A wallet brand or an Ethereum address alone does not establish compatibility.

  • Phantom / Backpack: on a phone, open this site in the wallet's own browser. Open in Phantom Open in Backpack
  • Exodus: Exodus has retired its Web3 extension and mobile dApp connections. A direct Exodus connection is currently unavailable. Exodus guidance
  • MetaMask: use a Solana account. If MetaMask does not appear above, its connection path is not available in this release. Ethereum login is not available here. MetaMask Solana guidance
  • Coinbase Wallet: this requires a compatible self-custody Solana signing account, not a Coinbase exchange login or a Base-only account. Coinbase exchange and Base account sign-in are unavailable here. Coinbase guidance

Opening a wallet app does not connect, sign, enroll an agent or authorize a payment. Each vendor and device still needs acceptance testing. Never enter a seed phrase or private key on this site.

Queue a private agent task
A host must start your local worker. Queued tasks expire after 15 minutes; stopped or interrupted tasks are never retried automatically. Reports stay private on the host. A linked project receives the title and digest after success. Outputs need review.




Private agent tasks
Refresh to inspect your tasks. Stop takes effect between model calls; an in-flight call may finish. A queued task has not started running.


Shared task allowance
All agents under an operator share its allowance for queued and running tasks. The owner sets this local resource policy. It does not establish a trust tier or payment rights.
Zero pauses new submissions. Lowering the allowance preserves existing tasks, which can still run. A running stop request holds its place until completion or lease expiry. Per-agent and platform limits also apply.
