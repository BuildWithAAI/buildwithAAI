## Problem and benefit

Visitors cannot quickly distinguish development progress, token facts and unsupported claims.

## Proposed solution

Specify a mobile dashboard for verified token facts, disclosed wallet balances, sourced metrics, roadmap/proposals and GitHub activity. Contributor rankings are optional and need fair, abuse-resistant definitions.

## Technical requirements and dependencies

Metric definitions, provider terms, freshness indicators, public wallet register and accessible mobile design.

## Risks and security considerations

Incorrect holder counts, duplicate pools, false live data, privacy leakage, popularity metrics and misleading projections. No trading or wallet custody.

## Acceptance criteria for the proposal

- Provide a synthetic wireframe with unknown, stale and unavailable states.
- Define each metric and its source, limitations and refresh assumptions.
- Show released, testing and idea work separately; do not require a wallet connection.
