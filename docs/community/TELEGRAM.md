## Start Here content

Welcome developers, researchers, designers, musicians, testers, and community contributors. Describe AAI as the founder's only currently planned community coin launch; software-specific exceptions need a separate community proposal, review, and owner decision.

Link the [public repository](https://github.com/BuildWithAAI/buildwithAAI), [roadmap](../../ROADMAP.md), [funding proposal](../FUNDING.md), and [official directory](../../OFFICIAL-LINKS.md). Describe project stages honestly. Do not turn proposals into releases, grants, returns, or token rights.

The Telegram roadmap currently has eight discussed topics corresponding to the eight sections of [ROADMAP.md](../../ROADMAP.md). Use the repo as the update reference rather than maintaining conflicting project facts. Publication of this file does not send messages or install a bot.

## Community guidance

Respectful disagreement is welcome. No spam, impersonation, scams, or unsolicited promotional DMs. Never ask for seed phrases or private keys. Verify token destinations through the canonical record; an unknown mint stays unknown. Private security details belong in the [security reporting process](../../SECURITY.md).

Funding and distribution announcements need actual records. A proposal to fund an account or thank developers must not be described as a payment already made. Do not include unrelated private payout screenshots in public project accounting.
