## Supply-chain / dev-machine (Binance, DarkSword, King lessons)
- No agent installs packages, extensions or repos on its own. Pin and hash every dependency, and review anything new for install scripts, obfuscation and lookalike names.
- Never run a "test task"/repo from a DM or recruiter on any machine that holds wallets, exchange logins or MT5. Install brew/tools from official sites only.
- iPhone: iOS ≥ 18.7.7 (or 26.3+). Remove seed photos/notes. Use Lockdown Mode if you hold large balances.
- Hot keys (King): any key the box can reach must hold one session's funds only, with no withdrawal rights.
